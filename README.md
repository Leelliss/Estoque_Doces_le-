## 🔧 Status
🚧 Projeto funcional em desenvolvimento

## 🎯 Objetivo do Projeto
Projeto desenvolvido para aplicar conhecimentos em C#, lógica de programação e estrutura de dados, por meio da criação de um sistema simples de controle de estoque via console.

## 📌 Sobre o Projeto
Sistema de controle de estoque voltado para o cadastro e gerenciamento de produtos (doces), permitindo:
- Cadastrar novos produtos  
- Listar produtos cadastrados  
- Atualizar a quantidade em estoque  
- Excluir produtos  
- Visualizar os dados no console  

## 🛠️ Tecnologias
- C#  
- .NET (Console Application)

## 🧠 Conceitos Aplicados
- Estrutura de dados  
- Lógica de programação  
- Interação com o usuário via console  

## 🚀 Como executar

1. Clone o repositório:
git clone https://github.com/Leelliss/Estoque_Doces_le-.git
2. Abra a solução no Visual Studio
3. Compile e execute com dotnet run ou diretamente no console
