# Estoque Doces

Projeto de sistema de controle de estoque em C#, criado como parte do meu aprendizado em Análise e Desenvolvimento de Sistemas.

## 📌 Sobre o projeto
Este sistema tem como objetivo controlar o estoque de produtos (neste caso, doces), permitindo:
- Cadastrar novos produtos
- Listar produtos cadastrados
- Atualizar a quantidade em estoque
- Excluir produtos
- Visualizar os dados no console

## 🛠️ Tecnologias
- C#  
- .NET (console application)

## 🧠 Conceitos aplicados
- Estrutura de dados
- Lógica de programação
- Interação com o usuário via console

## 🚀 Como usar
1. Clone o repositório
2. Abra no Visual Studio ou similar
3. Compile e execute no console
